Overview    
   
The booking system is a react-based application that enables efficient coordination between caterers and event bookers.
The system is dynamic and gives the possibility to adjust the use according to the needs of the catering and the criteria chosen thanks to the development of a generic code.
In addition, event owners enjoy quick service with maximum comfort while being able to compare prices, service, etc. between the various caterers.

Features


For those who book events:
1. Selection of catering for ordering by advanced and careful filtering.
2. Assembling a varied and orderly menu with the help of advanced filters.
3. Convenient and accessible ordering with details of interim payments.
4. Sending feedback after the event to the caterer.
5. Viewing the recommended caterers.

For catering owners:
1. Adding a new catering, editing, and deleting
2. Possibility to add and update the catering services in an organized way
3. Viewing the order board in a pleasant and accessible way
